LLMs for Automated Theorem Proving

Department of Computer Science, the University of Manchester

Supervisior: Konstantin Korovin

Background
Large language models (LLMs) have been very impressive and ubiquitous in many tasks such natural language processing, code generation, and query answering. LLMs show good reasoning abilities but it can be unreliable and quickly diverge after limited number of steps. On the other hand, automated theorem proving (ATP) is correct by construction and can produce proofs consisting of hundreds and thousands of steps. Nevertheless, ATP has its own limitations: search space can quickly explode, the proof search may get stuck and so on.

 

Description
This project is aimed at building a framework for utilising and experimenting with LLMs for tasks that can help automated theorem proving such as premise selection and proof guidance.

Deliverables

1. Framework for utilising and experimenting with LLMs for one of the tasks that can help automated theorem proving such as premise selection and proof guidance.

2. Evalaution of the framework for reasoning tasks
